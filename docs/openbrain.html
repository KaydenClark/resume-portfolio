OpenBrain — a personal RAG memory system

  • Supabase Postgres + pgvector
  • Custom MCP server
  • Serverless edge functions
  • Private repo — architecture shared here

What it is

OpenBrain is my personal memory layer: any thought, note, or decision I want to keep gets captured into a Postgres database with a vector embedding, and any AI client I use — desktop, editor, CLI — can retrieve it semantically. The repo stays private because the data is my life; the architecture is the interesting part anyway.

Architecture

Design decisions worth stealing

  • Dedup at capture, not cleanup. Content is fingerprinted and upserted — the most likely misuse (saving the same thought twice) is handled structurally.
  • Serverless on purpose. Edge functions mean no server to keep fresh, patch, or pay for while idle. The whole system runs on a free tier because it's designed to.
  • MCP as the interface. One protocol, every client. The memory outlives any particular AI tool.
  • Secrets stay server-side. Clients hold one access key; database credentials and model keys live in function secrets.

Why it's here

Same instinct as the work systems: quarantine the inputs, make the failure modes structural, and design so the operator — in this case, me at 11pm with a half-formed idea — can't quietly corrupt the data. This is what I build for fun, which is probably the most honest signal on this site.
