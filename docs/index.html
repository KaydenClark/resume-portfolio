// 03 — How I work

Four operating principles

  • Foreign systems are the job. Zendesk, Five9, Dialpad, Salesforce, Paycom — learn the export, own the pipeline. I'd never opened Zendesk before shipping a production reporting system from it in under 40 hours.
  • Design for misuse first. Wrong exports, skipped steps, and misleading charts are expected failure modes. Unmapped values fail loudly, QA checks gate publication, and validation is a workflow state — not a hope.
  • Handoff is part of the system. Everything ships with a README, a production SOP, and a change log. If it needs me to run it, it is not finished.
  • AI is a tool, not the pitch. I use agent workflows, control-doc harnesses, and eval frameworks to work faster, then keep human review between generated output and operational decisions.
